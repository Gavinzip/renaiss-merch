# Renaiss home preview

Review at `http://127.0.0.1:5173/v1.2/?preview=hub`. The home and its new API routes are development-only. Production Store routing is unchanged.

## Ownership

- `src/components/RenaissHub`: page composition, independent widgets, feed and preference hooks, bilingual copy, styles and hero playback. `hubWidgetPresets.ts` owns ready-made templates; `HubWidgetLibrary` owns selection and filling, `HubWidgetFields` the content slots, `HubWidgetEditor` the card controls, and separate motion/drag hooks the interaction lifecycle.
- `shared/hub-preferences.js` and its declaration: shared browser/server validation. Layouts contain 0–8 widgets. Core widgets are unique; feed widgets may repeat with independent source, project, region and post-count settings. Legacy AI widget entries are explicitly removed during validation because AI is now a separate dialog; other IDs, filters, sizes and order remain intact. An intentionally empty home is preserved.
- `server/hub/community-feed.mjs`: read-only adapter for the website's public `/api/intel/feed` source. Successful snapshots are shared for 60 seconds. A failed refresh produces an error, never stale or demo posts. The client refreshes every 5 minutes while visible.
- `server/hub/preferences.mjs`: SQLite records belong to the authenticated Renaiss session's `user.sub`. PUT uses the existing same-origin guard. Anonymous layouts use `renaiss.home.guest.v1` in browser storage. Guest and account layouts remain separate.
- `server/hub/hero-preview.mjs`: explicitly whitelisted local authoring files. These routes are disabled in production.
